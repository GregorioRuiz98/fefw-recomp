# Avisos de procedencia

Adaptación modificada para preparar localmente Fire Emblem: Fortune’s Weave. No es una distribución oficial del juego ni una publicación del mantenedor original del motor.

Base: [drakolordx7/pokopia-recomp](https://github.com/drakolordx7/pokopia-recomp/tree/2c29515b23a6d78d967775fd7e9f24f50402cca7), commit `2c29515b23a6d78d967775fd7e9f24f50402cca7`.

Las modificaciones se entregan como `project/patches/engine.patch`; las herramientas descargan esa revisión y aplican el parche localmente. Se conservan cabeceras y atribuciones. La adaptación añade configuración del título, preparación, pruebas y un configurador Win32, con cambios en traducción ARM64, servicios, vídeo y compatibilidad NVN2.

El texto GNU GPL v3 está en `LICENSE`. Se conservan las indicaciones de versión de cada archivo, incluida la opción de versiones posteriores donde corresponda. Los avisos MIT, Apache y otros de terceros no se sustituyen por una atribución genérica a este proyecto.

El configurador público contiene sus fuentes y recursos propios. Los componentes derivados del juego se generan localmente y no forman parte de esta distribución. Consulta [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) y [LEGAL.md](LEGAL.md).
